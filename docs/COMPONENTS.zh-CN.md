## 为什么不“把版本号直接改成最新”

`app/src/main/assets` 中的 DXVK、VKD3D、Box64、FEX、Turnip 都是为 Winlator 打包的专用资源。只修改 `arrays.xml` 的版本号不会产生对应二进制，最终会造成组件选择后找不到文件或容器启动失败。

因此本分支采用：

1. 先保留 3.1 已验证且比 Plus 更新的资源；
2. 上游版本单独记录；
3. 只有拿到/构建对应 Winlator 包并验证后才加入默认组件列表；
4. CI 固定关键源码依赖提交，保证 Release 可复现。


## E7G 多源内容机制

从 3.1-E7G.2 起，默认组件列表会合并：

1. `StevenMXZ/Winlator-Contents`（主源，优先）；
2. `E7G/winlator/components/contents-modern.json`（精选补充源）。

补充源只维护经过核对的现代组件，避免把大量重复或实验构建直接灌进列表。设置里的“可下载内容 URL”仍可自定义；也支持用分号或换行填写多个源。若使用默认主源，精选补充源会自动加入。
